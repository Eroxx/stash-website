Support

Stash is made by one person. If something is wrong, saying so actually reaches me.

What Stash is

A place to put links so you can find them again. It docks beside your browser on the Mac, saves the tab you are on with one key, and keeps everything in folders and tags you choose. Shopping lists carry prices and closing dates. Videos go in a queue. Your iPhone and iPad show the same library through your own iCloud.

Common questions

Stash is not reading my browser tab

The first time you save a tab, macOS asks whether Stash may control Safari or Chrome. If that was declined, open System Settings, go to Privacy & Security, then Automation, find Stash and switch your browser back on. macOS asks once per browser, so you may see it again the first time you save from a different one.

Clipping part of the screen does nothing

It needs Screen Recording permission, in System Settings under Privacy & Security. macOS only applies that permission the next time an app starts, so quit Stash and open it again after granting it.

A keyboard shortcut is not working

Something else on your Mac probably owns that key combination, and whichever app claimed it first wins. Open Settings in Stash and record a different one. Every shortcut in the list can be changed, including the one that clips the screen.

Can I keep my library on two Macs?

No, and Stash will tell you so rather than let you try. The library is a single file that is rewritten constantly. Two Macs writing to one copy through a syncing folder does not merge them, it keeps one and loses the other's changes. Your iPhone and iPad are safe because they never write that file directly.

Where is my library kept?

In a folder you pick, in Settings. It is ordinary readable JSON, so you can back it up, move it, or read it with anything. If you never choose one, Stash keeps it in its own Application Support folder.

Following a YouTube channel asks for a key

Channel following uses YouTube's own Data API, which needs a key tied to an account. Rather than route your requests through a server of mine, Stash asks you to paste in your own free key. Everything else about videos, including saving and playing them, works without one. Getting a key takes about five minutes:

  1. Open Google Cloud Console and sign in with any Google account.
  2. Create a project when it asks. Any name will do, such as "Stash".
  3. Open APIs & Services, then Library. Search for YouTube Data API v3 and press Enable.
  4. Open APIs & Services, then Credentials. Press Create credentials, choose API key, and copy the key it shows.
  5. Paste it into Stash on your Mac: Settings, under YouTube.

The key is free. Google allows it a generous number of requests each day, far more than following your channels uses, and it is never charged unless you add billing yourself.

How do I connect Claude?

In Stash, open Settings, go to AI apps and tick Let AI apps search your library. Tick the second box too if you want Claude to be able to save, file and tag links for you. Then use one of the two buttons:

  • Copy for Claude Desktop: in Claude, open Settings, then Developer, then Edit Config, paste it in, save, and restart Claude.
  • Copy for Claude Code: paste it into Terminal and press Return.

Any other app that speaks MCP can use the same address and token. To cut every app off at once, press New token. Claude can never delete anything from your library.

Do I need Obsidian?

No. If you happen to use it, you can point Stash at your vault and it will clip pages to notes and let you take notes on a video while it plays. If you do not, leave it unset and none of that appears anywhere.

Is there a Windows or web version?

No, and there are no plans for one. Stash is a Mac app with iPhone and iPad companions.
